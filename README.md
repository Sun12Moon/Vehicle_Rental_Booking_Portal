# Vehicle Rental Booking Portal

## Project Purpose
The Vehicle Rental Booking Portal is a comprehensive platform for users to rent vehicles. It manages bookings, vehicle inventory, customers, payments, and rental agreements.

## Technology Stack
- **Frontend**: React.js + Vite, Tailwind CSS, React Router DOM
- **Backend**: Node.js + Express.js
- **Database**: MySQL 8.x (Raw SQL)
- **Authentication**: JWT + bcrypt

## Repository Structure
- `frontend/`: React application (Vite)
- `backend/`: Node.js Express server
- `database/`: SQL schema, queries, seeds
- `docs/`: Project documentation
- `postman/`: API collections
- `assets/`: Static assets

## How to Start Frontend
```bash
cd frontend
npm install
npm run dev
```

## How to Start Backend
```bash
cd backend
npm install
npm run dev # (requires setting up start scripts, or use `node server.js`)
```

## Development API Base URL
`http://localhost:5000/api/v1`
